# CineMozi - Timeless Edition

Plataforma interativa para avaliação conjunta de filmes, álbuns de música (com roleta 3D e player de prévia) e livros, integrada ao Firebase e com automações em FastAPI hospedadas no Render.

## 📂 Estrutura do Projeto
- `index.html`: Front-end completo da aplicação hospedado no GitHub Pages.
- `backend/main.py`: API em FastAPI para rotas e tarefas automatizadas.
- `backend/requirements.txt`: Dependências do Python.
- `backend/serviceAccountKey.json`: Chave de configuração segura do Firebase Admin.
